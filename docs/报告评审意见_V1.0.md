## 0. 总体评价

**结论：这是一份质量明显高于常见"DIY QRNG 方案书"的工程报告，可以作为立项与实验设计的依据；但它目前处于"物理上讲得通、工程上关键一环缺失"的状态——直接照做会在 ADC 环节拿不到可用熵。**

最突出的优点是**敢于"不宣称"**：报告反复区分"物理原理成立 / 数据手册可查 / 本项目建议 / 必须实验确定"四类陈述，并明确否定了"SP800-22 通过 = 安全""QRNG = OTP 安全""IDQ 用 LED 是选错熵源"等常见错误论断。§3.3、§3.4、§4.2、§12.3 属于"审稿人挑不出错"的水平。

| 维度 | 评价 | 说明 |
|---|---|---|
| 物理原理正确性 | 优 | 散粒噪声、分束器场关系、共模抑制、差分噪声相加均正确 |
| 数值与量纲自洽性 | 优 | 抽查 20+ 处数值全部复算无误（见 §5） |
| 文献与引用可靠性 | 良 | 两篇关键文献已核实；一条 Hamamatsu 链接实测 404 |

| 完整性 | 中 | 缺 BOM/成本、进度、比特率估算、健康测试、漂移校准 |

## 1. 值得肯定的具体内容（建议保留）

1. **§2.2 单边谱约定**写明 `S_i,shot = 2qI_ph`、`i_shot = √(2qI_ph)`，并强调"报告、代码和仪器软件必须统一谱定义"。多数错误都源于单/双边谱混用，这条堵得对。
2. **§3.3** 否定"软件减固定噪声"：电子噪声是随机时间序列 `e(t)` 而非固定偏置，从单次样本 `x=q(t)+e(t)` 中减去一个 RMS 值不能恢复 `q(t)`。这正是民间方案最容易翻车处。
3. **§3.4** "两路独立电子噪声差分后功率相加（+3 dB）"并给出净收益条件；**§3.6** 结论是"值得搭建并 A/B 比较"而非"必然更优"。
4. **§4.2 表格**把 IDQ（LED+CMOS 像素阵列）与本项目（DFB+分束+双 PIN）在光源/探测器/观测量/模拟结构/优劣逐维对比，并明确"不应把 IDQ 描述为选错熵源"。事实准确、立场公允。
5. **§9.3** 禁止用 `random.gauss` 之类 PRNG 补齐缺失样本、必须保存原始 ADC 码而非只存 0/1、四类数据分别存档——可审计性的底线写得很好。
6. **§12.3/§12.4** OTP 与完整性分离、认证标签绑定明文字段、信息论认证需独立密钥、量子计算不破解正确使用的 OTP 但整体安全取决于密钥配送——全部准确。
7. **§11.3** 公平比较条件（相同总光功率/频带/量程/时长/窗函数）可直接作为实验 SOP。

## 2. 必须修改的问题（A 类：不改会导致实测拿不到数据或结论错误）

### A1【最关键】ADC 动态范围与"差分增益不宜过高"互相矛盾，缺口达 40~60 dB

§9.1 已意识到"8 bit 量化可能限制动态范围"，但 §8.6 又写"最终差分增益不宜过高，以免差分后的直流失调或残余共模信号使输出饱和"。两条合在一起的结果是：**按报告给的参数搭出来，量子噪声根本进不了 ADC**。定量算一遍（每臂 100 µW、R=0.95 A/W、Rf=10 kΩ、带宽 10 MHz）：

| 项目 | 数值 |
|---|---|
| 单臂光电流 | 95 µA |
| 单臂散粒噪声 | 5.52 pA/√Hz |
| OPA847 输入电流噪声（数据手册 f>1 MHz） | 2.50 pA/√Hz |
| Rf=10 kΩ 热噪声 | 1.29 pA/√Hz |
| 单路合计 | 6.19 pA/√Hz → 输出 61.9 nV/√Hz |
| 10 MHz 内单路积分噪声 | 195.8 µV rms |
| **差分输出积分噪声** | **277 µV rms** |
| 每路直流输出（噪声"骑"在其上） | 0.950 V（噪声/直流 = 206 ppm） |
| Hantek 6022BE 8 bit @5 Vpp 的 LSB | 19.53 mV |
| **量子噪声占 LSB** | **0.014 LSB** → 每样本熵 ≈ 0 bit |

即：不平衡时直流 0.95 V、噪声 0.28 mV，8 bit 下噪声不足 1 个码值；即使把量程压到 2 Vpp，也只有 0.036 LSB。需要的后级增益（差分后、ADC 前、AC 耦合）：

| 目标 σ | 8 bit / 5 Vpp | 8 bit / 2 Vpp | 16 bit / 5 Vpp |
|---|---|---|---|
| 1 LSB | +37.0 dB | +29.0 dB | −11.2 dB |
| 5 LSB | +50.9 dB | +43.0 dB | +2.8 dB |
| 10 LSB | +57.0 dB | +49.0 dB | +8.8 dB |
| 20 LSB | +63.0 dB | +55.0 dB | +14.8 dB |

**修改建议**
- 架构改为 `差分 → 隔直/高通（拐点 ≪ 频带下限，如 100 kHz） → 交流增益 40~60 dB（可分级、带限幅保护） → ADC`；
- 删除或改写 §8.6 "差分增益不宜过高"，改为"差分级的**直流**增益必须低（失调不放大），**交流**增益必须高（把量子噪声送进 ADC 有效位），二者由隔直网络分离"；
- 验收项增加："噪声占码值数 σ/LSB ≥ 5 且无削顶"；
- 若坚持不做高增益后级，则必须换 ≥14 bit 采集设备，并说明成本变化。

### A2 缺"目标模拟频带"的决策——这是全文最关键的未定参数

附录 B 里写着"TIA 目标带宽：待确定"，但 Rf、Cf、噪声积分、ADC 增益、比特率、乃至 CMRR 要求全都由它决定。§8.4/§9.1 都把结论推给"待定"，等于核心设计没有闭环。

**修改建议**：直接给出推荐值与理由，例如 **1–10 MHz**：
- 避开 DFB 低频 1/f 型 RIN、市电 50/100 Hz 及谐波、开关电源尖峰（§10.4 已列该风险）；
- 与 OPA847 在 Rf=10 kΩ 下的可用带宽（约 16 MHz，见 A5）及 6022BE 的 20 MHz 模拟带宽匹配；
- 与 ADC 采样率匹配（48 MSa/s 采 10 MHz 带内信号仍需**抗混叠低通**，报告未提这一环）；
- 给出"为什么不是 100 kHz，也不是 100 MHz"的量化理由（带宽 ↑ 则总噪声 ↑ 但比特率 ↑；RIN 随频率下降有利于量子占比）。

### A3 报告自己举的 100 µW 工作点，达不到自己定的"量子噪声高 10 dB"标准

§7.2 以"每臂 100 µW"举例，§11.4 要求"目标频带内量子噪声分量高于电子噪声底"并提到"≥10 dB 作为后续目标"。两者联立（OPA847，电流噪声 2.50 pA/√Hz）：

- 100 µW（95 µA）：量子 5.52 ÷ 电子 2.81 pA/√Hz → **仅 5.9 dB**，不达标；
- 达到 10 dB 需要散粒噪声 ≥ 8.89 pA/√Hz → **光电流 ≥ 247 µA → 每臂 ≥ 260 µW**；此时 Rf=10 kΩ 的直流输出已 2.47 V，需确认 OPA847 在 ±5 V 下的摆幅是否够用。

**修改建议**（二选一并写入报告）：
1. 保留 OPA847，把每臂光功率提到 **≥0.26 mW**，并重算 Rf/Cf/摆幅/结温；
2. 或换**低偏置电流（FET 输入）TIA**：TI 在 OPA847 数据手册中明确"跨阻 >100 kΩ 时建议用 JFET 输入运放（如 OPA657）"。若电子噪声只剩 Rf 热噪声 1.29 pA/√Hz，则 95 µA 时量子占比 **12.6 dB**，100 µW 工作点反而成立——但需核对该器件的最小稳定增益与 Cf 条件。

### A4 OPA847 的输入偏置电流必须量化（±19 µA，不能只写"不可忽略"）

§8.5 只写"输入偏置电流并非可忽略到任意程度"。查 OPA847 数据手册电气特性：**Input Bias Current = ±19 µA (typ)，−39/−41/−42 µA (max)**；偏置电流漂移 15 nA/°C (typ)、最高 70 nA/°C；**Input Current Noise Density (f>1 MHz) = 2.5 pA/√Hz (typ)**。这两个数互相印证（√(2q·19 µA) = 2.47 pA/√Hz）。后果：

- 直流失调：19 µA × 10 kΩ = **190 mV**（单臂）；两只器件符号不同，差分后仍可能差上百 mV，直接吃掉后级增益余量；
- 电流噪声 2.5 pA/√Hz 与 5.52 pA/√Hz 的散粒噪声同量级（+0.79 dB），且**两路独立、差分不消除**，会稀释量子占比；
- 温漂 0.15 mV/°C，配合 50~60 dB 后级增益时会缓慢顶到轨。

**修改建议**：按 TI 数据手册 Figure 3 的做法在**同相输入端接 12 kΩ 到地以抵消偏置电流失调**（并说明该电阻带来的 1.15 pA/√Hz 热噪声须计入预算），或改用低 Ib 器件；并把"Ib 补偿方案"列入 §8.9 的必填输入。

### A5 OPA847 的稳定判据没写出来：Cf ≤ Cs/11，直接决定带宽上限

§8.4 只写"用 Ctot 初步估算再仿真"。TI 手册给的是闭式条件：**高频噪声增益 NG2 = 1 + Cs/Cf 必须 ≥ 最小稳定增益 12**，即 `Cf ≤ Cs/11`。代入本项目结电容：

| 总输入电容 Cs | Cf 上限 | Rf=10 kΩ 时 −3 dB 带宽 |
|---|---|---|
| 8 pF | 0.73 pF | ≈21.9 MHz |
| 11 pF（G8376-03 的 5 pF + 运放 3.9 pF + 寄生） | 1.00 pF | ≈15.9 MHz |
| 15 pF | 1.36 pF | ≈11.7 MHz |

这条结论很有用：它说明（a）TIA 带宽被"稳定判据"卡在 ~16 MHz，与 6022BE 的 20 MHz 恰好匹配；（b）想提高带宽只能**降 Rf**（从而放宽 Cf 需求），代价是输出噪声电压变小、需要更多后级增益。建议写入 §8.4，并补"Ctot 实测方法（断开 PIN 测输入电容）"。

| 编号 | 缺项 | 建议 |
|---|---|---|
| B1 | **噪声预算表（dB 汇总）** | 把 §2.2/§2.3/§2.4/§7.2 的分散公式合成一张表：输入"单臂光电流"，逐项列 shot / RIN / 运放电压噪声 / Rf 热噪声 / 运放电流噪声 / ADC 量化与前端噪声，输出"量子占比 X dB、差分后 SNR Y dB"。这是设计报告的核心表格，目前缺失 |
| B2 | **CMRR 的定量设计判据** | §3.5 只给了定义。可补一条极简公式：散粒噪声极限等效于 `RIN = 2q/I`（95 µA 时 = **−144.7 dBc/Hz**），故 **所需 CMRR ≈ RIN(dBc/Hz) − (−144.7) dB**。例：RIN = −120 dBc/Hz 需 > 24.7 dB，留 10 dB 余量即 > 34.7 dB。这样"要匹配到什么程度"第一次有了数字依据，也直接支撑 §11.4 的验收项 |
| B3 | **可达成比特率估算** | 全文没有"这个原型最终能出多少 bit/s"。给个保守算式即可：`R ≈ BW × H_sample × 量子占比修正`；并说明 6022BE 单次 1 M 样本的限制（8 bit、σ=10 LSB、按 800-90B 保守取 2~3 bit/样本 → 单次记录可产 ~2~3 Mbit，连续率受 USB 流限制）。没有这个数，就无法判断 §12.5 的"短信/低速语音"密钥消耗是否被覆盖 |
| B4 | **健康测试（Health Tests）** | §9.5 只提"以 800-90B 为参考估计最小熵"。800-90B 强制要求**上电自检 + 连续健康测试**（Repetition Count Test / Adaptive Proportion Test）与失败处置策略。应给出窗口长度、cutoff、告警停机逻辑，以及"健康测试失败后禁止继续取密钥"的状态机 |
| B5 | **温漂与 CMRR 校准周期** | §7.3 只有一句"记录两臂功率和温度，测试漂移"。建议量化：光功率平衡漂移 1% 对应多少 CMRR 退化（用 B2 公式反推）、校准周期（每次上电/每小时）、是否需要在线抖动注入做自动平衡 |
| B6 | **BOM 成本与进度** | 标题主打"低成本"但没有成本表。需要重点论证的是：**带 TEC 的 10 mW 1550 nm DFB + 低噪声恒流驱动**很可能比其余器件之和更贵；若确要低成本，应讨论"更低功率 DFB / 去 TEC + 外部温控"的取舍，并给总价区间与采购周期 |
| B7 | **6022BE 的两个实测确认项** | （1）双通道同时开启时真实采样率是否降为 24 MSa/s（Nyquist 降到 12 MHz）；（2）驱动/软件是否存在隐式抽取、平均、自动量程。§9.1 提了"应先确认"但没给方法。建议补：注入已知频率正弦看是否出现混叠/抽取镜像；同一信号单/双通道对比 FFT |
| B8 | **PIN 极端工况** | 报告举到"每臂 5 mW → 4.75 mA"。需核对 G8376 的**最大光电流/最大入射功率**与结温引起的暗电流上升（InGaAs 暗电流约每升 10 °C 翻倍），否则 §7.2 的 5 mW 一行可能超出安全工作区，还会因发热导致两臂失配漂移 |

## 4. 表述与物理措辞的修正建议（C 类：不影响结论，但影响专业性）

- **C1（§3.1）** 本项目实际结构是"单束激光 50:50 分束 + 双探测 + 电子学相减"，其物理实质是**测量分束器空端口的真空涨落（分束/分区噪声）**，"本振"就是被分束的同一激光场。建议点明，并补理论依据：两路电流相减后噪声下限正是 `Var(Δi) = 2q(I₁+I₂)`（与经典强度噪声无关，只要两臂匹配）。把这条写成"熵源存在的物理依据"，理论链条才闭合。
- **C2（§3.2）** 模型 `i₁(t)=R₁TP(t)+n₁(t)` 没有散粒噪声项，易让读者误解为"差分后只剩经典噪声"。建议写成 `i₁ = R₁TP(t) + i_shot,1 + i_elec,1`，并说明 `i_shot` 两路独立（不可差分消除）、`R₁TP` 的涨落部分两路相关（可差分消除）。
- **C3（参考文献）** [4] Hamamatsu G8376 的链接我实测返回 **404**（不排除站点反爬），建议核对并换为有效链接；因此 §6.3 表格中的暗电流/截止频率/结电容/有效面积**我无法独立核实**，请以最新数据手册复核（−03/−05 的暗电流上限常随版本更新）。[1] Gehring 与 [9] Masalov 我已用 Crossref 核实无误，[9] 后面"正式引用前请核对"的注记可删（RSI **88**, 113109 (2017)，DOI 10.1063/1.5004561 确认存在）。
- **C4（§7.4）** 1550 nm 的准确表述是"对视网膜相对安全（光在到达视网膜前被角膜/晶状体吸收），但高功率下**角膜**仍会被灼伤"，"不能依赖眨眼反射"是对的，可补一句"主要风险部位是角膜而非视网膜"。
- **C5（§6.6）** "≈1 M 点存储深度"建议写成"1 M 样本/通道（以实际固件版本为准）"。

## 6. 建议的修改优先顺序

1. **A1**（ADC 动态范围方案）——不改则整个数据链拿不到熵；
2. **A2**（确定 1–10 MHz 目标频带）——它是 A1/A3/A5 的共同输入；
3. **A3 + A4**（工作点与 OPA847 偏置电流）——决定"量子占比"能否达标，直接影响熵估值；
4. **A5**（Cf ≤ Cs/11）——决定 TIA 能不能稳定工作；
5. **B1 + B2**（噪声预算表与 CMRR 判据）——把上面几步的结论固化成可审计的表；
6. **B3 + B4**（比特率与健康测试）——回答"能做到什么程度"与"如何证明"；
7. **B6**（BOM/成本）——支撑标题里的"低成本"；
8. **C1–C5**（措辞与引用）——最后一轮润色。
